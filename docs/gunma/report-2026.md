# 群馬県35市町村対応 チェック結果レポート（令和8年度）

作成日: 2026-11-11 ／ 対象: `requests/20261111-群馬県中の市町村の対応の件.md` の段取り1〜9

## まとめ

- **群馬県の全35市町村のページを作った。** 高崎市は従来どおり `index.html`、ほかの34市町村は `<ローマ字>.html`（例: `maebashi.html`）。
- 税率は群馬県の「[令和8年度 実際の市町村別国民健康保険税率](https://www.pref.gunma.jp/uploaded/attachment/701029.pdf)」を正とし、マスター（`tools/gunma/master-2026.json`）に転記した。市町村の公式ページで確認できた税率は、すべてこの表と一致した。
- **市町村のExcel（試算表）がある9市町村（高崎市以外）は、Excelで計算した1,350件（各150件）と照合した。** 4市（桐生・伊勢崎・太田）と沼田市の149件は完全一致。残りの差は、**すべてExcel側の誤りか古い値が原因**で、Excelの条件に合わせて計算するとExcelの値と1円単位まで一致することを確かめた（下の「Excelとの差」）。
- Excelがない富岡市・伊勢崎市・みどり市の**公式の計算例5件**もすべて再現できた（5割軽減・2割軽減・世帯主が社保の例を含む）。
- 情報が足りない市町村は、分かる範囲で計算ルールを作り、**画面に注意書きを出す**ようにした（例: 「子ども・子育て支援金分は、〇〇村のホームページで確認できていないため、県の資料の額で計算しています」）。
- 新しく作った34市町村のルールセットは、2026-11-11 に確認を受けて `status: reviewed` にした（画面に「参考値」と表示）。

## Excelとの照合（段取り3・6）

### 方法

1. `tools/gunma/gen-golden.mjs` が世帯のテストケースを作る（1市町村150件。一般・低所得（軽減あり）・高所得（限度額に届く）を混ぜる）。
   年度の途中で40・65・75歳になる、就学する、18歳になる、といった境目をまたぐ人は入れない（多くのExcelが通年・年齢入力のため）。
2. `tools/gunma/lo_eval.py` が LibreOffice で市町村のExcelにケースを入力し、区分ごとの税額と合計を読み出す → `app/tests/golden/<団体コード>-2026.json`
3. `app/tests/golden-gunma.test.ts` が同じケースをアプリの計算エンジンで計算し、区分ごと・合計を比べる。
4. 差が出たときは、Excelの数式を読んで原因を特定し、`app/tests/golden/excel-diffs.json` に書く。テストは「Excelの条件に合わせたエンジンの結果」がExcelと一致することを確かめる（理由を書くだけでは通らない）。

Excelの機能に合わせて範囲を絞った（例: 軽減を計算しないExcelでは、エンジンも「未申告」扱いで比べる）。各Excelの対応範囲は `golden/<コード>-2026.json` の `meta.domain`。

### Excelとの差（すべてExcel側の問題）

アプリは国の基準（地方税法）と市町村の税率ページに合わせて計算している。市町村のExcelとは次の点で結果が変わることがあり、各市町村のページの「ご注意」に書いた。

| 市町村 | Excelの問題 | 確かめ方 |
|---|---|---|
| 藤岡市 | 令和8年度の欄の課税限度額が改正前（医療分65万円・支援金分24万円）。市の税率ページは67万円・26万円 | 限度額をExcelの値にすると30件すべて一致 |
| 館林市 | 給与所得控除が改正前（令和6年分まで、最低55万円）の表。令和7年分は最低65万円 | 改正前の表で計算すると22件すべて一致 |
| 沼田市 | 「給与所得者等」を給与所得・年金所得が0より大きいかで判定（計算表!T列）。給与収入55万円超65万円以下の人が数えられない | 判定基準をExcelに合わせると一致 |
| みどり市 | 18歳未満の世帯員の所得を、子ども・子育て支援金分の所得割に含めない（18歳未満で軽減されるのは均等割だけ） | 18歳未満の所得を除いて子ども分を計算すると18件すべて一致 |
| 中之条町 | ①軽減判定の式（入力シート!O63）が1行ずれたセルと比べていて、7割軽減は所得0の世帯にしか付かず、5割の判定に7割の基準額を使っている ②65歳以上の年金の特別控除15万円を2回引いている ③軽減判定用の給与所得に改正前の給与所得控除を使っている ④未就学児の均等割軽減を支援金分にかけていない ⑤みどり市と同じく18歳未満の所得を子ども分の所得割に含めない | Excelが判定した軽減割合と④⑤をExcelに合わせると79件すべて一致 |
| 板倉町 | 給与所得者等が0人の世帯で、軽減判定の基準額を10万円低く（33万円）計算している | 基準額を33万円にすると8件すべて一致 |

そのほか気づいたこと（計算には影響しない）:

- みどり市のExcelは、入力シートの税率表に医療分の限度額を66万円と表示しているが、計算には67万円を使っている。
- 太田市・館林市のExcelの欄外の説明（軽減の基準額「33万円」など）は古い。
- 中之条町のExcelは日付が「1904年起算」の設定（照合ツールで対応済み）。

## 情報が足りない市町村の扱い（注意書き）

市町村のページで確認できなかった項目は、県の資料や国の基準で補って計算し、ページ上部の「〇〇の計算についてのご注意」に出す。

| 注意書き | 出す条件 | 該当 |
|---|---|---|
| 税率は県の資料による | 市町村のページで税率を確認できない | 前橋市・榛東村・吉岡町・上野村・南牧村・長野原町・嬬恋村・草津町・高山村・昭和村 |
| 子ども・子育て支援金分は県の資料の額で計算 | 市町村のページで子ども分を確認できない | 榛東村・吉岡町・上野村・南牧村・長野原町・草津町・高山村・昭和村 |
| 課税限度額は国の基準額と仮定 | 限度額を確認できない | 前橋市・榛東村・吉岡町・上野村・南牧村・長野原町・嬬恋村・草津町・高山村・昭和村 |
| 軽減判定・端数処理は国の基準と高崎市の方法 | Excelも公式の計算例もない | Excelがなく、計算例もない24市町村 |
| 試算表（Excel）での照合はしていない | Excelがない | Excelがない25市町村 |
| 試算表（Excel）と結果が違う場合がある（理由つき） | Excelに上の問題がある | 沼田市・館林市・藤岡市・みどり市・中之条町・板倉町 |

資産割のある安中市・昭和村は、固定資産税額の入力欄を出し、「資産割があります」と書いた。
