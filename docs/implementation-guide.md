# 高崎市 国民健康保険税 試算ロジック 実装ガイド

元資料: [request20261005-01.md](request20261005-01.md) / 参照実装: 旧jQuery版 `10/index.html`（このリポジトリには含めない） の head 内 JS（`calcTax()`）、ヘルパー: `10/common/js/common.js`

毎年の制度改定時は、**「4. 年度ごとに書き換える定数」** と **「7. 改定時チェックリスト」** を見れば作業できるようにまとめている。

---

## 1. 全体像

国保税 = **医療分 + 支援金分（後期高齢者支援金等分） + 介護分** の3区分の合計。
各区分は同じ構造で計算する。

```
区分税額 = 所得割額 + 均等割額 + 平等割額
```

| 項目 | 計算 | 単位 |
|---|---|---|
| 所得割額 | 対象者の課税所得の合計 × 所得割率(%) ÷ 100 | 世帯合計に対して |
| 均等割額 | 1人当たり均等割額 × 対象人数 | 人数に比例 |
| 平等割額 | 1世帯当たり平等割額（固定） | 世帯に1回 |

最終: `国保税 = 医療分税額 + 支援金分税額 + 介護分税額`

## 2. 入力値（フォーム `#form1`）

被保険者を1行ずつ入力する（`data-add-template="続柄"` の行が1人分。「追加」「削除」ボタンで増減）。

| name | 内容 | 備考 |
|---|---|---|
| `所得:続柄` | 本人 / 妻（夫）/ 子 など | 1行目は「本人」固定(readonly)。**空欄の行は人数に数えない** |
| `所得:年齢` | 年齢 | 介護分の対象判定（40歳以上）に使う。空欄は 0 扱い |
| `所得:所得` | 所得（円） | `Number()` で数値化 |

フォームの `change` イベントで `calcTax()` が毎回全再計算される（追加/削除ボタンも `trigger('change')` する）。

## 3. 計算手順（`calcTax()` の流れ）

### 3-1. 被保険者ごとの課税所得

```
課税所得 = max(所得 - 基礎控除, 0)        // 基礎控除は 1人当たり 430,000円（令和7年度以前の例: 43万円）
```

- 続柄が入力されている人だけが対象。
- 区分ごとに対象者リストを作る:
  - 医療分: 続柄あり全員
  - 支援金分: 続柄あり全員
  - 介護分: 続柄あり **かつ 年齢 >= 40**（※コード上は上限なし。制度上は40〜64歳。後述の注意点参照）
- 各リストの `人数` = 件数、`世帯の総課税所得` = 課税所得の合計。

### 3-2. 区分ごとの税額

3区分とも同じ式。パラメータだけ違う。

```
所得割額 = 世帯の総課税所得 × 所得割率 / 100
均等割額 = 均等割額(1人当たり) × 人数
平等割額 = 平等割額(1世帯当たり)
税額     = 所得割額 + 均等割額 + 平等割額
```

介護分のみ: **対象人数が0なら所得割・均等割・平等割をすべて0にする**（平等割の誤加算防止）。

### 3-3. 端数処理・上限

1. 表示用の区分税額は `floor100orLess`（100円未満切捨て）。
2. 年税額の上限（賦課限度額）を超えたら上限額に置き換える（alert を出す）。
   - 医療分 650,000円 / 支援金分 220,000円 / 介護分 170,000円
3. `国保税 = 医療分税額 + 支援金分税額 + 介護分税額`

### 3-4. 計算例（元コメントより）

世帯3名・世帯の所得200万円（本人のみ所得あり）のケース。

**医療分**
- 所得割: (200万 − 43万) × 6.4% = 100,480円
- 均等割: 24,200 × 3 = 72,600円
- 平等割: 21,400円
- 合計 194,480 → 100円未満切捨て **194,400円**

**支援金分**
- 所得割: 157万 × 2.2% = 34,540円
- 均等割: 7,400 × 3 = 22,200円
- 平等割: 5,800円
- 合計 62,540 → **62,500円**

**介護分**（40〜64歳 1名）
- 所得割: 157万 × 2.0% = 31,400円
- 均等割: 9,400 × 1 = 9,400円
- 平等割: 6,100円
- 合計 46,900円 → **46,900円**

**国保税合計 = 194,400 + 62,500 + 46,900 = 303,800円**

> 注意: 例の「所得200万」は被保険者全員で基礎控除が引かれる実装では、人数が増えると課税所得の合計が変わる。上の例は「所得ありの人が1名、他は所得0」の場合の数字（所得0の人の課税所得は0）。

## 5. 画面への出力（`data-item` 規約）

計算結果は `data-item="…"` を持つ要素の `data-item-val` 属性に書き込み、CSS 側（`::after` 等で `attr(data-item-val)` を表示する想定）で見せる方式。

| data-item | 内容 |
|---|---|
| `{区分}-1` | 被保険者の所得（万円単位・`price10k`） |
| `{区分}-2` | 基礎控除（万円単位） |
| `{区分}-3` | 所得割率 |
| `{区分}-4` | 所得割額 |
| `{区分}-5` | 均等割額（1人当たり） |
| `{区分}-6` | 人数 |
| `{区分}-7` | 均等割額（合計） |
| `{区分}-8` | 平等割額 |
| `{区分}-9` | 区分税額（100円未満切捨て後） |
| `{区分}課税所得` | 被保険者ごとの課税所得計算式の親要素（子の1つ目をテンプレートとして複製） |
| `課税所得の計算の続柄` / `課税所得の計算の小計` | 上記テンプレート内。続柄名と課税所得（万円） |
| `医療分` / `支援金分` / `介護分` | 上限適用後の区分税額 |
| `国保税` | 合計 |

`{区分}` = `医療分` / `支援金分` / `介護分`。

課税所得の計算式の描画手順:
1. `data-item="{区分}課税所得"` の最初の子をクローンしてテンプレートにする。
2. 初回ループで既存の子を全削除し、被保険者ごとにクローンして append。
3. 小計の幅は直前の行と揃える（`removeAttr('style')` → `Math.max(prevWidth, width)`）。

### ヘルパー（common.js）

| 関数 | 動作 |
|---|---|
| `numberFormat(n)` | `Intl.NumberFormat` で3桁区切り |
| `price10k(n)` | `floor(n / 10000)`（円→万円、画面の式表示用） |
| `floor100orLess(n)` | `floor(n / 100) * 100` |

## 6. 現行実装の注意点・既知のクセ（改善候補）

1. **端数処理と上限判定の順序**: 表示値は100円未満切捨て済みだが、上限比較と最終合計（`国保税`）は切捨て前の値を使う。上限未満の場合、合計が各区分の表示値の合計と100円単位でずれうる。→ 切捨てを税額確定時に1回だけ行うのが望ましい。
2. **上限判定が `>=`**: ちょうど上限でも alert が出る。`>` が自然。alert は入力のたびに出るため UX も悪い（画面内メッセージ推奨）。
3. **介護分に上限年齢（64歳）が無い**: 65歳以上は介護保険料（国保税ではなく介護保険）なので、`40 <= 年齢 <= 64` にすべき可能性が高い。
4. **コピペ構造**: 医療/支援金/介護の処理が3回コピーされている。区分ごとの設定オブジェクトを定義して1つの関数でループすると、年度改定時の修正が1箇所で済む（下記参照）。
5. **未使用変数**: `医療分/支援金分/介護分 = new Array(10)`、`所得`、`基礎控除１世帯当たり`。
6. **所得割額は小数のまま**: `×率/100` で小数が出る。表示 `numberFormat` は小数も出し得る。端数処理方針の確認が必要。
7. **軽減・特例が未実装**: 7割/5割/2割軽減、未就学児の均等割軽減、後期高齢者支援金の移行（75歳到達）、減免、旧被扶養者減免などは現状なし。改定で要望が出やすい箇所。
8. **クローンの取り方**: 追加ボタンは `:nth-child(2)` を複製元にしており（1行目は「本人」固定のため）、DOM構造変更時に壊れやすい。

## 8. 実装リファクタ案（再実装時の参考）

純粋関数に切り出すとテストしやすい。

```js
const 年度設定 = {
  基礎控除: 430000,
  限度額: { 医療分: 650000, 支援金分: 220000, 介護分: 170000 },
  区分: {
    医療分:   { 所得割率: 6.4, 均等割: 24200, 平等割: 21400, 対象: p => true },
    支援金分: { 所得割率: 2.2, 均等割: 7400,  平等割: 5800,  対象: p => true },
    介護分:   { 所得割率: 2.0, 均等割: 9400,  平等割: 6100,  対象: p => p.年齢 >= 40 && p.年齢 <= 64 },
  },
};

function 国保税計算(被保険者, 設定 = 年度設定) {
  const 人 = 被保険者
    .filter(p => p.続柄)
    .map(p => ({ ...p, 課税所得: Math.max(p.所得 - 設定.基礎控除, 0) }));

  const 結果 = {};
  for (const [名, c] of Object.entries(設定.区分)) {
    const 対象 = 人.filter(c.対象);
    if (対象.length === 0) { 結果[名] = 0; continue; }
    const 所得割 = 対象.reduce((s, p) => s + p.課税所得, 0) * c.所得割率 / 100;
    const 合計 = 所得割 + c.均等割 * 対象.length + c.平等割;
    結果[名] = Math.min(Math.floor(合計 / 100) * 100, 設定.限度額[名]);
  }
  結果.国保税 = 結果.医療分 + 結果.支援金分 + 結果.介護分;
  return 結果;
}
```

※ 上記は「切捨てを1回・上限は切捨て後に適用」とした改善版。現行コードと完全一致させたい場合は、6-1 の挙動差に注意。

## 9. テストケース（現行定数）

| ケース | 入力 | 期待値 |
|---|---|---|
| A | 3名（本人 所得200万・年齢50、他2名 所得0・年齢<40）※介護対象なし | 医療 194,400 / 支援金 62,500 / 介護 0 / 合計 256,900 |
| B | 3名のうち1名が40歳以上で所得0、本人所得200万（本人も40歳以上でないなら介護対象外） | 介護分は対象者の課税所得のみ按分。元コメントの例（介護対象1名・所得200万）で 46,900 |
| C | 全員所得 0 | 医療 = 24,200×人数+21,400 を100円未満切捨て |
| D | 所得が非常に高い（例: 2,000万） | 医療 650,000 / 支援金 220,000 / 介護 170,000（上限） |
| E | 続柄が空の行を含む | 空の行は人数に含めない |
| F | 介護対象者なし | 介護分 = 0（平等割も加算しない） |

ケースAの合計は計算例（3-4）の医療+支援金に介護0を足した値。3-4 の 303,800円 は「本人が40歳以上で介護対象、本人の所得200万、世帯3名」の場合。
