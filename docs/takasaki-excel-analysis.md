# 高崎市「国民健康保険税試算表」Excel 解析メモ（令和8年度）

- 出典ページ: https://www.city.takasaki.gunma.jp/page/3607.html
- 解析対象: `xlsx/2026-102024.xlsx`（Excel本体はGit管理外。[xlsx/README.md](../xlsx/README.md)）（シート: 入力[表示] / 計算[非表示] / 税率・条件[非表示] / Sheet1[非表示・旧高崎の平等割軽減区分表]）
- 解析方法: openpyxl で数式を全読み。**実際の値での検証（試算例との突き合わせ）は未実施。**
- 位置づけ: これが「正」の計算ロジック。旧jQuery版（`10/index.html`、リポジトリ外）の計算は大幅に簡略化されている。

## 1. 現行アプリ(10/index.html)との差分（重要）

| 項目 | 現行アプリ | 市のExcel |
|---|---|---|
| 区分 | 医療・支援金・介護 | + **子ども分**（4区分） |
| 所得の入力 | 所得（円）1つ | 給与収入・年金収入・その他所得・固定資産税額（収入→所得への変換が必要） |
| 生年月日 | 年齢のみ | 生年月日（1/1時点の年齢、介護/未就学/18歳未満/75歳到達の判定を月単位で） |
| 加入期間 | 年間固定 | **月単位**（年度途中の加入月・脱退月） |
| 軽減 | なし | 7割/5割/2割、未就学児均等割5割減、子ども分の18歳未満均等割免除、平等割1/2・1/4軽減（旧高崎のみ） |
| 上限 | 年額で単純に頭打ち | **月割り限度額**（月ごとに限度額/12を超えると所得割を再按分） |
| 端数 | 100円未満切捨てを表示のみ | 個人ごとの項目ごとに円未満切捨て、区分合計は100円未満切捨て |
| 限度額 | 650,000/220,000/170,000 | 670,000/260,000/170,000/**30,000(子ども)** |

→ 現行コードの流用は難しく、**エンジンは作り直し**が前提。

## 2. 税率・条件シート（値）

| 区分 | 所得割 | 資産割 | 均等割 | 平等割 | 限度額 |
|---|---|---|---|---|---|
| 医療分 | 6.8% | 0% | 27,400 | 21,400 | 670,000 |
| 後期支援分 | 2.5% | 0% | 9,700 | 6,900 | 260,000 |
| 介護分 | 2.1% | 0% | 10,600 | 6,100 | 170,000 |
| 子ども分 | 0.3% | 0% | **1,300** | 800 | 30,000 |

- **子ども分の均等割（解決済み）**: Excelの1,300円 = 税率表の「1,200円 + 18歳以上均等割100円」。18歳未満は1,200円が全額軽減されて0円、18歳以上は1,300円。Excelの式（18歳未満・未就学は0、それ以外1,300）と一致する。
  根拠: 市の計算例ページ(3607)の子ども分「3,600円＋200円−軽減1,200円＝2,600円」、および他自治体資料の「軽減分は18歳以上の均等割に上乗せ」。
- **公式の試算例（3607ページ、令和8年度）**: 3人世帯（本人42歳 営業所得250万円、妻38歳、子12歳 所得なし）。医療244,300 / 支援金87,700 / 介護60,100 / 子ども9,600 / 合計**401,700円**。
  → 同じ入力をExcel(HyperFormula)で計算した結果と**完全一致**（`tools/oracle/example.mjs`）。
- 基礎控除 430,000 は計算シート内に直書き（`税率・条件` に無い）。
- 軽減判定: 7割 基本430,000 / 5割 基本430,000+加算310,000×被保険者数 / 2割 基本430,000+加算570,000×被保険者数。
  いずれも `+ (給与所得者等の人数-1) × 100,000`（5割・2割は M26=給与所得者等数、7割は R20=同人数）。
- 給与所得者等要件基準額: 給与収入 550,000超 / 年金収入(65歳未満) 600,000超 / (65歳以上) 1,250,000超。
- 年金軽減判定加算額: 150,000（65歳以上の年金所得から引く）。
- 未就学児均等割減額率: 0.5。
- 全地区の設定。`Sheet1`は旧高崎地区の平等割軽減(1/2,1/4)の区分表（入力C25で選択: 軽減なし/1/2軽減/1/4軽減）。

## 3. 計算フロー（被保険者ごと、最大8人）

### 3-1. 年齢区分（1/1時点, 年度Y=8 のとき基準日=令和8/1/1。コード上は `C1+2018` で西暦化）
- 誕生日 <= 1953/1/1 → 65歳以上（Y基準で+1953年）
- 誕生日 > (Y+2012)/4/1 → 未就学
- 誕生日 > (Y+2000)/4/1 → 18歳未満
- それ以外 → 一般
- 介護対象: 40歳以上65歳未満（月ごとに判定。`F > 基準-65年` かつ `F <= 基準-40年`）
- 後期高齢者: 75歳到達月以降は国保から外れる（月単位で●が付かなくなる）

### 3-2. 所得の算出
1. **給与所得** = 給与収入から給与所得控除を引く。特例軽減「該当」の世帯主以外は ×0.3（`D`列）。
   給与所得控除（収入→控除後）:
   - 〜650,999: 0（≒650,000以下は0）
   - 651,000〜1,899,999: 収入−650,000
   - 1,900,000〜3,599,999: floor(収入/4,000)*4,000*0.7−80,000
   - 3,600,000〜6,599,999: floor(収入/4,000)*4,000*0.8−440,000
   - 6,600,000〜8,499,999: 収入*0.9−1,100,000
   - 8,500,000〜: 収入−1,950,000
   - ※給与850万超の所得金額調整控除は非対応（注意メッセージのみ）
2. **年金所得** = 年金収入*率/100−控除額（0未満は0、小数切捨て）。
   - 65歳未満: 〜1,299,999→100%−600,000 / 1,300,000〜→75%−275,000 / 4,100,000〜→85%−685,000 / 7,700,000〜→95%−1,455,000 / 10,000,001〜→100%−1,955,000
   - 65歳以上: 〜3,299,999→100%−1,100,000 / 3,300,000〜→75%−275,000 / 4,100,000〜以降は上と同じ
   - 公的年金以外の合計所得が1,000万円以下の前提。
3. **給与と年金の併用控除**（`E`列）: 給与所得+年金所得 < 100,000 → 0。それ以外は `min(給与,100000)+min(年金,100000)−100000` を控除（`F=D−E`）。
4. **所得計** `N = F + 年金所得 + その他所得`
5. **課税標準**（医療・支援・子ども） `O = max(N−430,000, 0)`。介護分は `P`（40〜64歳の加入月がある人のみ）、同じ式。

### 3-3. 軽減判定用所得（`Q`列）
- 給与所得は併用控除を軽判用(L列基準)に置き換え、65歳以上の年金所得は150,000を引く（150,000未満は0）。
- `Q = H(給与所得・軽判) + L(年金所得・軽判) + その他所得`（基礎控除は引かない）。
- 軽減判定所得合計 `M31 = ΣQ`。**ただし対象者は、世帯主は常に含め、世帯主以外は「世帯の最初の加入月に被保険者だった人」だけ**（計算!Q6/R6 の `BB6<>BB20 なら対象外`）。後期高齢者へ移った人（75歳以上）の所得や、年度途中で加入した人は軽判所得・給与所得者等の人数に入らない。ゴールデンテストで判明（実装: `app/src/engine/calculate.ts`）。
- 適用軽減率 `M34`: 強制軽減が指定されていればそれ。未申告なら0%。`M31<=7割基準`→70% / `<=5割基準`→50% / `<=2割基準`→20% / それ以外0%。
  - 7割基準 = 430,000 + (給与所得者等の人数−1)×100,000（人数0なら+0）
  - 5割基準 = 430,000 + 310,000×被保険者数 + (給与所得者等−1)×100,000
  - 2割基準 = 430,000 + 570,000×被保険者数 + (給与所得者等−1)×100,000
- 「給与所得者等」該当(R列): 給与収入>550,000 または 年金(65歳以上>1,250,000／未満>600,000)。
- 世帯の申告状況が「全員申告済み」のときだけ軽減判定を行う（「未申告者有り」だと軽減なし）。
- 所得に応じた均等割・平等割の軽減は**簡略対応**（特定同一世帯所属者の軽減判定・条例減免は非対応、とExcelの注意書きにある）。

### 3-4. 個人別・区分別の税額（年額換算、1人分）
軽減率 `r = M34` として、各区分で:
- 所得割 = floor(課税標準 × 所得割率/100)
- 資産割 = floor(固定資産税額 × 資産割率/100)（高崎市は率0）
- 均等割 = floor(均等割額 × (1−未就学なら0.5) × (1−r))
  - 介護分は未就学の減額なし（対象が40〜64歳なので無関係）
  - **子ども分は18歳未満・未就学は0円**（`B列` が「未就学」「18歳未満」）。子ども分は未就学5割減の式を使わず0。
- 平等割（世帯に1回。表示は人ごとの列にもあるが世帯で1つ）= floor(平等割額 × (1−r) × [1/2軽減:0.5, 1/4軽減:0.75, なし:1])
  - 介護分・均等割は軽減率のみ。介護分の平等割に旧高崎の1/2・1/4は掛けない
  - 平等割は加入者が1人以上いる場合のみ。介護分は介護加入者が1人以上いる場合のみ

### 3-5. 加入月と月割り（年度途中の加入・脱退に対応）
- 月×人のマトリクス（4月〜3月）に ●（医療・支援・子ども対象）▲（均等割なし＝未就学・18歳未満）■（介護対象）を立てる。
- 判定: 生年月日が当月未満の年齢（誕生前は対象外）、75歳到達月以降は対象外、「社保等」なら空欄、`加入月L`〜`脱退月M` の範囲か。
- 月ごとの税額 = (その月に加入している人の課税標準合計×率)切捨て ÷ 12 を小数第2位で丸め、均等割・平等割も同様に1/12。
- 年額 = 月額の合計（小数2位）→ ROUND(…,1) の整数切捨て（`BR`列）。

### 3-6. 限度額（月割り限度額）
- 月ごとに「世帯の月額合計 > 限度額/12」かを判定（`BE`列）。
- 超えた月は、所得割と資産割を再按分して月額を調整する（均等割・平等割は固定）:
  - 医療/介護/子ども: `限度額/12` を ROUND 2桁、後期のみ ROUNDDOWN 2桁
  - 調整後の所得割 = 限度額/12 − (均等割+平等割)
- 該当月数を「◯ヶ月該当」と画面に表示。
- 最終: 各区分 `ROUNDDOWN(区分合計, -2)`（100円未満切捨て）。年税額 = 医療+後期+介護+子ども。
- 「保険税額（加入月分）」は、各月のセル合計（`L25:N30` の月別税額）で、端数調整はしないと明記。

## 4. JSON/エンジン化の方針（案）
- **データ(JSON)**: 区分ごとの率・額・限度額、軽減の基準額、給与所得控除表、年金控除表、年齢区分の境界、特例（旧高崎の平等割軽減など）。
- **エンジン**: 上記 3-1〜3-6 を汎用ステップとして実装し、自治体JSONの値と選択肢で動く。
- 高崎市以外では「資産割あり」「4方式」などが出るので、`資産割` を最初から持たせる（高崎は率0）。
- 月単位のロジックは複雑なので、まず **年間加入のみ** で実装し、月割りは第2段階にする選択肢もある（Excelは「加入者全員が年間加入の場合」を計算シート見出しに書いている）。
